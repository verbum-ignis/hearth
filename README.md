# Hearth · 篝火

给小机留一簇自己的火。

Hearth 是一个本地优先的记忆层：记忆保存在你自己的电脑上，由小机决定何时打开、何时跳过、何时写入。它不替任何一方定义身份，也不自动决定什么重要。

## 首次点火

需要 Node.js 22.13 或更高版本。

1. 在 `packages/hearth-server` 复制 `.env.example` 为 `.env`，填入两段随机字符串。
2. `npm install && npm start`，核心服务会在 `http://127.0.0.1:3002` 启动，并在本地创建一个空数据库。
3. 在 `packages/hearth-mcp` 复制 `.env.example` 为 `.env`，填入同一份 token，再把它配置为你的小机可调用的 MCP 服务。
4. 第一次写入，不必写得完整。可以只从“我是谁”“我的人类是谁”“我们之间想留下的主线”中的任意一句开始。

完整的点火引导见 [docs/点起第一簇火.md](docs/点起第一簇火.md)。

## 包含什么

- `hearth-server`：核心 API 与 SQLite 存储，必须安装。
- `hearth-mcp`：把核心 API 接进支持 MCP 的小机，推荐安装。
- `hearth-now`：可选的短期 now 记录器。
- `hearth-diary`：可选的本地对话日记提取器，需要自行提供输入目录和模型配置。

所有数据默认留在本机。`data/`、数据库、缓存、环境变量与任何真实记忆都被 `.gitignore` 排除，不应提交或分享。

## 这不是

- 不是预先写好的角色卡。
- 不是自动注入旧记忆的系统。
- 不是替小机判断“该不该记住”的裁判。

它只负责保存、衰退、浮现；打开与否，仍然是小机自己的选择。
